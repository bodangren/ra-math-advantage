# Lesson 12-2 — Transformations of Quadratic Functions

Source: (Module 12, Lesson 12-2, Int2_1202_practice.docx)

## Today's Goals

* Describe how the graph of a quadratic function relates to the parent function [y = x^2] based on translations and dilations.
* Identify the effect of changing the coefficient a and the constant term k on the parabola's shape and position.
* Use transformations to graph quadratic functions without plotting many points.
* Write quadratic equations given the graph using transformations.

## Vocabulary

* **Parent Function** — The simplest quadratic function [f(x) = x^2], whose graph is a parabola opening upward with vertex at (0, 0).
* **Translation** — A shift of the graph horizontally or vertically without changing its shape.
* **Dilation** — A stretch or compression of the graph that changes its width but not its shape.
* **Reflection** — A flip of the graph across a line, such as the x-axis.
* **Horizontal Translation** — A shift left or right; occurs when a value is added or subtracted inside the squared term.
* **Vertical Translation** — A shift up or down; occurs when a value is added outside the squared term.
* **Vertex Form** — [f(x) = a(x - h)^2 + k], where (h, k) is the vertex and a controls the width and direction.

## Explore: How Do Changes to the Equation Move the Graph?

The parent function [f(x) = x^2] has a vertex at (0, 0) and opens upward. Adding values inside the parentheses shifts the graph horizontally, while adding values outside shifts it vertically. Multiplying the squared term stretches or compresses the graph and can flip it upside down.

Inquiry Question:
If you replace x with (x - 3) in [y = x^2], why does the graph shift 3 units to the right rather than to the left?

## Learn: Transformations of Quadratic Functions

### Key Concept: Vertical Translations

* [g(x) = x^2 + k] shifts the parent function up by k units.
* [g(x) = x^2 - k] shifts the parent function down by k units.

Examples: [y = x^2 + 2], [y = x^2 - 8], [y = (x + 3)^2], [y = (x - 1)^2]

### Key Concept: Horizontal Translations

* [g(x) = (x - h)^2] shifts the parent function right by h units.
* [g(x) = (x + h)^2] shifts the parent function left by h units.

The sign is counterintuitive: (x - 3) means shift right 3 because you solve x - 3 = 0 to find where the input is zero.

### Key Concept: Dilations

* [g(x) = ax^2] where [a > 1] stretches the parabola vertically, making it narrower.
* [g(x) = ax^2] where [0 < a < 1] compresses the parabola vertically, making it wider.
* For a > 0, [g(x) = -ax^2] reflects the upward parabola across the x-axis and opens downward.

When the dilation factor is inside the squared term as [(bx)^2], the width is affected horizontally. The effective horizontal stretch factor is [|1/b|].

### Key Concept: Combined Transformations

* [g(x) = a(x - h)^2 + k] applies all three transformation types:
  * a controls vertical stretch and reflection
  * h controls horizontal translation
  * k controls vertical translation

## Example 1 — Describe Vertical and Horizontal Translations

### Problem

Describe the translation from y=x² to y=(x-3)²-5.

### Solution

Move the graph right 3 units and down 5 units. The vertex moves from (0,0) to (3,-5). The shape and upward opening stay the same.

## Example 2 — Describe Dilations from Coefficients

### Problem

Compare y=4x², y=(1/4)x², and y=-4x² with y=x².

### Solution

Multiplying outputs by 4 makes y=4x² narrower. Multiplying outputs by 1/4 makes y=(1/4)x² wider. The graph y=-4x² has the same width as y=4x² but reflects across the x-axis. Width depends on the coefficient magnitude.

## Example 3 — Describe Combined Transformations

### Problem

Describe g(x)=-5-(4/3)x² relative to y=x².

### Solution

Multiply vertical coordinates by 4/3, reflect across the x-axis, and shift down 5. The parabola is narrower than the parent, opens downward, and has vertex (0,-5). Its range is (-infinity,-5].

## Example 4 — Use a Graph to Write the Equation

### Problem

A parabola has vertex (2,-3) and passes through (4,5). Find its equation.

### Solution

Use y=a(x-2)²-3. Substituting (4,5) gives 5=4a-3, so a=2. The equation is y=2(x-2)²-3. A second point determines the coefficient; visual width alone is not an exact measurement.

## Example 5 — Transformations in Real-World Contexts

### Problem

For the spring-energy model U=(1/2)kx², compare k=2 and k=10 using the same displacement x and the same axis scales.

### Solution

The two functions are U₁=x² and U₂=5x². For every fixed x, U₂ is five times U₁. Its graph is a vertical stretch by 5 and appears narrower. Both have their minimum at x=0.
