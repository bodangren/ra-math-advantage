# Business Math capability graph

The graph has 87 candidate skill nodes and two assessment tasks for 89 published lessons. Some lessons have additional objectives that still need atomic review. Each node records its lesson and competency standards. Each prerequisite edge needs source review to establish a capability dependency.

The activity map refers to the actual published activity keys. It does not derive capabilities from the problem family registry. The map separates guided practice, assessment, and independent work.

Numerical checks measure their stated calculation. A saved model or explanation requires teacher review. Do not treat submission, phase completion, or a numerical quiz result as proof of every application skill.

The graph is available in the development review page. It does not activate adaptive knowledge-state updates. The selected accounting-equation pilot is gated and remains draft. It cannot run until the node, blueprint, activities, writer, and teacher-review publication checks pass. `kstApplied: false` remains correct until the runtime integration verifies the prerequisite model and evidence policy.

Review checks compare graph coverage with the published curriculum. They check unique activity mappings, valid edge endpoints, cycles, named standards, and the distinction between automatic and manual evidence. A published lesson activity is not automatically exact-node evidence. Source references identify the authored curriculum. No generated family is used as a curriculum source.
