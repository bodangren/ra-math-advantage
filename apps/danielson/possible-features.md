# Possible features

## AI coaching brief

Status: Possible feature. Do not implement. User instruction: 2026-09-07.

A supervisor selects published observations and requests a draft brief.
The brief summarizes evidence, suggests one focus, and provides coaching questions.
It can suggest practice from the approved technique library and a follow-up evidence check.
Each factual claim links to its source. Suggestions carry a clear label.
The brief states when evidence is insufficient.

The supervisor reviews and edits the draft before publication.
AI does not assign ratings, change plans, or recommend employment decisions.
Private leadership comments are excluded from teacher-facing generation.
Use the existing evidence and curriculum. Generate on request.
Save only accepted feedback. A separate vector database is not required for this scope.
Start with summaries and coaching questions. Pilot accuracy, correction frequency,
unsupported claims, and preparation time before adding practice suggestions.
