Line numbers refer to the reviewed lesson source files. Some corrections also require changes to copied seed text and lesson plans. Check the original worksheet when the lesson omits a diagram or changes a problem statement. Do not infer missing numerical givens from a sketch.

## Verification method

The three-variable and arcade systems were solved with exact rational Gaussian elimination. The regression coefficients were computed with exact rational normal equations. The reported R² uses 1 − SSE/SST. Trigonometric values were checked by substitution and by the period of the function. The radio-tower units were checked against text extracted from the original DOCX.

Check each corrected expression in the original equation. For counts, state whether order matters before choosing a denominator. For inequalities, check both sign cases and exclude undefined points. For fitted models, state the fitting method and the observed data interval.
