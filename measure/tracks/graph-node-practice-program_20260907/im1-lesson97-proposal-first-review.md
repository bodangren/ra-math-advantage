### Correct Problem 33

Replace `Recover integer joint and marginal frequencies from relative frequencies and a grand total` with a bounded conversion capability such as `Estimate joint and marginal counts from rounded relative frequencies and a grand total`.

The printed percentages multiplied by 215 produce nonintegers. For example, `42% × 215 = 90.3` and `4% × 215 = 8.6`. Thus, the source cannot support an exact-count key that treats the percentages as exact. More than one integer table can be compatible with percentages rounded to whole numbers.

An authored task must state a rounding or reconciliation rule. It must accept all integer tables that satisfy that stated rule. If the response only gives the completed table, use the existing broad table-construction capability. Record the new conversion capability only when calculations or another separate response show the percentage-to-count method. Do not award both capabilities from one unexplained final table.
