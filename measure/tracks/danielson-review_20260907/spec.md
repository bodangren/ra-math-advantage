# Danielson Review

Review the current Danielson application. Check access control, observations, reporting, and improvement plans. Verify findings with tests or concrete code traces. Do not apply fixes.

## Expanded Scope

Review all app areas, including teacher-training curriculum, content completeness, source alignment, usability, accessibility, workflows, data integrity, security, tests, operations, and unnecessary code. Retain prior findings. Record evidence and review limits. Do not claim that a review proves the absence of all defects.
