# Curriculum and Content Review

Correction status: see [Review corrections](fixes.md). The findings below describe the review baseline.

Date: 2026-09-07. Scope: all 63 published technique modules.

## Method and limits

Each row covers the description, action steps, detailed summary, quotation field, alignment label, book reference, and configured demonstration video. Each module was compared with its matching local Teach Like a Champion 3.0 source extract. The comparison focused on the technique definition and teaching steps. It was not a line-by-line verification of every research claim in the book.

“No additional mismatch identified” means that this pass did not find a further technique-definition error. It is not a content certification. Shared quotation and citation issues still apply. Source page markers can include adjacent techniques. They identify the extract and are not a replacement bibliography.

Video status comes from YouTube oEmbed metadata on this review date. A 404 indicates that the configured resource was unavailable through that endpoint. Successful metadata does not prove playback, classroom relevance, caption quality, or access on the school network.

## Findings across the library

- Fourteen pages need a substantial correction to their technique definition or core method. They are marked **Rewrite** below.
- Twenty-seven numeric page ranges do not overlap the page markers in their matching source extracts.
- Four reference fields contain a technique or chapter identifier. The renderer incorrectly prefixes each with “Pages”. Three modules have no literature entry.
- Sixty-two modules have a quotation field. An exact normalized-text search found only one in its matching extract: Regular Revision. The other 61 need attribution checks. This search is a screening result. It does not establish that all 61 are fabricated.
- Twelve of 38 configured videos return 404. Threshold and Strong Start points to Schoolhouse Rock, Conjunction Junction.
- Twenty-five modules have no configured demonstration video. Video is optional in the existing Learn specification. This is a training resource gap, not a violation of that specification.
- Remove unsupported universal rules and causal claims. Distinguish an adaptation from the named source technique.
